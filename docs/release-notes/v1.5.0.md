### 🐟 闲鱼管家 Xianyu Copilot v1.5.0 —— 对标「闲鱼管家 xianyu-guanjia」全面增强

#### 💬 消息中枢（全新）
- 内置闲鱼 IM 长连接（`wss-goofish.dingtalk.com`）：每个账号独立连接，`/reg` 注册 + 15s 心跳 + 推送 ACK，断线指数退避重连，令牌每小时自动续期；
- 会话列表、聊天记录、未读角标、按买家 / 消息 / 商品搜索；支持从闲鱼拉取会话列表与历史消息；
- App 内直接回复买家；在手机闲鱼或 App 内人工回复后自动进入「人工接管」，N 分钟后自动恢复。

#### 🤖 自动回复 / AI 客服
- 关键词回复（包含 / 精确、`|` 多词、按账号 / 商品限定、优先级），商品专属回复，默认回复（可每会话只发一次）；
- AI 回复：OpenAI 兼容接口（DeepSeek / 通义 / Kimi / OpenRouter…）与 Anthropic Claude，可配 Base URL / Key / 模型；
- AI 议价：最大优惠百分比 / 金额、最大议价轮数、单品底价；提示词可在 App 内编辑；
- 敏感词过滤（替换 / 拦截）、连发防抖、会话冷却、重复内容去重、回复测试。

#### 📦 发货增强
- IM「我已付款，等待你发货」消息即时触发发货，订单轮询保留为兜底；两条入口共用幂等任务表 + 卡密 CAS，绝不重复发货；
- 延时发货（分钟）、发货模板（`{卡密}` `{卡密列表}` `{订单号}` `{买家}` `{商品}` `{规格}` `{数量}` `{时间}` `{附言}`）；
- 发货内容通过闲鱼消息私信给买家；卡密不足时不再空发，改为失败告警；低库存预警。

#### 🧾 订单 / 🛍️ 商品
- 订单中心：IM 与轮询发现的订单统一入库，状态、来源、发货任务进度，一键补发 / 查询详情；
- 商品管理：擦亮、一键擦亮、每日定时擦亮、改价、下架、重新上架；
- 采集复制：粘贴闲鱼商品链接 → 解析标题 / 描述 / 价格 / 图片 → 转存图片并预填到发布页。

#### 🔔 通知
- 企业微信、钉钉（加签）、飞书（加签）、Bark、Telegram、自定义 Webhook + 本机系统通知；
- 可按事件订阅：新消息、新订单、发货成功 / 失败、库存不足、账号失效。

#### 📊 首页看板
- 今日消息 / 订单 / 成功发货 / 营收、IM 连接状态、未读、待发与失败任务、低库存提示。

#### ⚠️ 需要真机校准
IM 推送字段路径、订单号提取、订单详情接口参数、轮询订单的 buyerId / itemId 字段均移植自参考项目，尚未用真实账号抓包验证。解析失败只会少收消息或回退到订单轮询，不会影响原有自动发货与账号状态判定。
