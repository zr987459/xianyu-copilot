# 产品需求文档 (PRD): Xianyu Copilot 闲鱼智能协同与全自动化运营系统

## 1. 项目定位与背景
借鉴 `zhinianboke/xianyu-auto-reply` 与 `xianyu-mobile` 的工业级电商架构设计，结合 `XianyuAutoAgent` 深度多专家博弈大模型能力，打造一款轻量级、低资源消耗且具备高颜值移动端 UI 的闲鱼自动化运营协同系统。

## 2. 目标用户与使用场景
- **目标用户**：闲鱼个人卖家、数码二手卖家、虚拟资源与卡券店主。
- **核心场景**：
  1. 手机端随时随地监控买家消息、订单与在售宝贝。
  2. 买家进店砍价与咨询参数时，AI 机器人全自动阶梯议价、守住价格底线。
  3. 虚拟商品/激活码/网盘资料付款后秒级自动私信下发，并自动调用官方接口确认发货。
  4. 支持单码快捷录入、批量多行导入卡密，实时追踪每张卡密的核销状态。
  5. 免浏览器一键上传图片与发布上架商品。

## 3. 功能清单与模块划分

### 3.1 移动端 App / Mobile UI (对齐 xianyu-mobile)
- **4 大底部导航 Tab**：
  - **消息 (Messages)**：实时会话列表、多轮人机对话气泡、未读标记、滑动操作。
  - **订单 (Orders)**：订单流转状态（等待付款/等待发货/已发货/交易成功）、手动重发、复制单号。
  - **商品与发货 (Products & Delivery)**：
    - 三段式分栏：在售商品列表、复合发货规则（固定内容+卡密池）、卡密库存与核销流水。
    - 卡密资产管理：单码录入、批量导入、在库未使用/已发放状态筛选。
  - **我的与设置 (Mine & Settings)**：
    - 账号状态与 Cookie 保鲜监控。
    - AI 多专家 Prompt 在线配置（意图分类、阶梯降价策略、客服话术）。
    - 运行模式（自动回复 / 人工接管句号切换）。

### 3.2 服务端后端能力 (FastAPI + Async SQLite)
- **长连接与协议直连**：WSS 协议长连接、心跳保活、Token 自动刷新。
- **多专家 Agent 引擎**：兼容 Anthropic-messages 与 OpenAI 规范，支持 Thinking 思考链过滤。
- **自动发货引擎**：
  - 支持固定内容模式、卡密池模式、复合组合模式。
  - 自动调用官方 `mtop.taobao.idle.logistic.consign.dummy/1.0/` 无需物流接口。
- **商品发布引擎**：
  - 官方 `stream-upload` 图片流式上传。
  - `mtop.idle.pc.idleitem.publish` 免浏览器单品发布。

## 4. 验收标准
- 手机/Web 界面交互丝滑，符合 Material 3 与移动端手势交互设计。
- 零 Docker 强依赖，在低配服务器或手机本地 PRoot 均能秒级启动。
- 自动化发货与 AI 砍价闭环 100% 跑通，卡密绝不重复发放。
