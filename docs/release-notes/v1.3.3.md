### 🐟 闲鱼管家 Xianyu Copilot v1.3.3

#### 核心网络修复
- **强制 HTTP/1.1 协议**：OkHttp 强制使用 `Protocol.HTTP_1_1`，彻底根除手机开启代理/VPN 或处于移动网络时与阿里网关 HTTP/2 握手 RST 造成的 `connection closed`。
- **补齐 PC 网页端请求头**：增加 `Connection: keep-alive`、`Sec-Fetch-Site`、`Sec-Fetch-Mode` 等标准头。
- **网络容错自愈**：当导入 Cookie 遭遇偶发网络超时或断连时，提示明确网络诊断（而非直接断定失效），如库内无活跃账号则自动激活，避免用户被错误卡在未激活状态。

#### 界面与状态优化
- **状态标签多色支持**：失效状态显示浅红 `需重新登录` 标签，在线状态显示清新绿，避免英文 `EXPIRED` 混淆。
- **弹窗与刷新联动**：导入后无论校验是否完全通过，弹窗均自动关闭并刷新账号列表，杜绝“必须重启 App 才能看到新账号”的体验问题。
- **活跃账号判定加固**：数据库 `getActiveAccount()` 严格按 `is_active = 1` 查询，杜绝无激活账号时误把未激活账号标为“使用中”。
