# 系统架构设计 (ARCHITECTURE): Xianyu Copilot

## 1. 架构总览
```
+-----------------------------------------------------------------+
|                        移动端 UI / Web App                      |
| (4 大 Tab: 消息列表 | 订单状态 | 商品与卡密发货 | 我的设置)       |
+-----------------------------------------------------------------+
                                | HTTP RESTful / WebSocket
+-----------------------------------------------------------------+
|                       FastAPI 核心控制层                        |
|  - 状态监控 API   - 规则与卡密 API   - 商品发布 API   - 提示词 API|
+-----------------------------------------------------------------+
          |                                  |
+--------------------+            +-------------------------------+
|  SQLite 持久化引擎  |            |   闲鱼底层长连接与自动化引擎  |
| - 消息历史与上下文  |            | - WSS 消息监听与 ACK 回执     |
| - 卡密池与核销记录  |            | - AI Agent 多专家决策网关     |
| - 发货规则与商品库  |            | - 虚拟商品官方无需物流自动发货 |
+--------------------+            | - stream-upload 官方图片上架  |
                                  +-------------------------------+
                                                 |
                                  +-------------------------------+
                                  |     闲鱼服务端 & 大模型接口    |
                                  | - goofish.com / dingtalk.com  |
                                  | - Anthropic / OpenAI 兼容网关 |
                                  +-------------------------------+
```

## 2. 核心设计原则
1. **轻量低耗 (Zero Overheat)**：摒弃重型 Docker 容器与无头浏览器，改用纯原生异步 HTTP / WebSocket 协议，手机与 VPS 均可秒级启动运行。
2. **移动优先 (Mobile First)**：UI 设计深度对齐 `xianyu-mobile` 的蓝白 Slate 质感设计系统，提供清晰的 4 大底部 Tab 与抽屉操作。
3. **复合发货机制**：彻底解决只能二选一的局限，同一个宝贝可同时下发网盘下载链接与独享卡密。
4. **大模型多协议中立**：内置协议适配层，无缝直通 Anthropic-messages 与 OpenAI 规范。
